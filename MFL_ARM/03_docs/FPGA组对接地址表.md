# MFL 共享 DDR 地址表 —— FPGA ↔ ARM 对接版

> 一句话口径: **FPGA 侧 AXI 地址 = DDR 物理地址，无偏移**
> 单一事实源: 本表 + ARM 侧驱动寄存器头文件（fpga_regs.h）

---

## 一、地址分配总表（物理地址，FPGA 侧直接使用）

| 区域 | 物理地址 | 窗内偏移 | 尺寸 | 读/写归属 |
|---|---|---|---|---|
| **控制邮箱** | `0x301000` | `0x1000` | 页 64B（已用 8×32bit = 32B） | ARM 写/FPGA 回写（详见二） |
| **IN slot0**（输入帧） | `[0x302000, 0x46A000)` | `0x2000` | **1,474,560 B 实占**（=3×480×1024=0x168000） | ARM 写 → FPGA 读 |
| **final OUT**（推理结果） | `[0x470000, 0x47B400)` | `0x170000` | 46,080B | FPGA 写 → ARM 读 |
| **scratch A**（层间缓存） | `0x500000` | `0x200000` | 8MiB 名义（conv00 最大实占 0x780000，止于 0xC80000，见注 2） | FPGA 专用（偶层写） |
| **scratch B**（层间缓存） | `0xD00000` | `0xA00000` | 8MiB | FPGA 专用（奇层写） |
| **IN slot1**（输入乒乓） | `[0x1500000, 0x1700000)` | `0x1200000` | **预留 2 MiB** | ARM 写 → FPGA 读 |
| 保留/勿用 | `0x300000~0x301000` 前页 / `0x301040~0x302000` / `[0x46A000, 0x470000)` 间隙 24,576B / `[0x47B400, 0x500000)` 间隙（OUT 末址之后） | — | — | 勿用 |

- 共享窗总范围：**`0x300000 ~ 0x4300000`（64MiB）**，`/dev/uio0` 已由设备树圈出，Linux 不占用。**`0x4300000` 是窗顶**，顶外无共享窗、勿寻址。
- **窗内自由区 = `[0x1700000, 0x4300000)`，共 44 MiB**。自由区新需求走变更流程后使用。
- 注 1（slot 容量不对称）：slot0 与 OUT 0x470000 仅隔 24,576B，**不得按 2MB 写入**；slot1 后无邻接区、可按 2 MiB 用满。两槽容量不对称，驱动侧双缓冲容量检查按 slot0 口径（1,474,560B）。
- 注 2（scratch A 尾部）：conv00 无池化最大输出 16×480×1024=7,864,320B（0x780000），实占止 0xC80000；**尾部空闲 [0xC80000, 0xD00000) 共 512KiB**，其中 **[0xC80000, 0xC90000) 64KB 临时用作 BIST**（与逐层调试导出互斥）。scratch A 其余名义范围同样勿作他用。

## 二、控制邮箱寄存器（物理 0x301000，8 × 32bit）

### 六字（0x00~0x14）

| 偏移 | 寄存器 | 方向 | 语义 |
|---|---|---|---|
| +0x00 | IN_ADDR | ARM 写 | 输入帧起始地址（运行时；L0 引擎从读该值起） |
| +0x04 | OUT_ADDR | ARM 写 | 末层输出地址（运行时；引擎 `layer==stop_l` 时写该值） |
| +0x08 | SLOT | — | **引擎忽略**（层间地址=层奇偶固定），勿写语义值 |
| +0x0C | CTRL | ARM 写 bit0=start | **FPGA 受理后写 0 清除**（防重复触发；读回 0 可当受理回执） |
| +0x10 | STATUS | FPGA 写（ARM 只读） | 四值编码：**0x0**=idle（上电/软复位后）/ **0x1**=busy / **0x2**=done / **0x6**=done\|ERR；**0x4**=仅 ERR 未 DONE，为保留值（读到按错误处理；其余未定义组合值 0x3/0x5/0x7 同样按错误处理）**。位语义：bit0=BUSY、bit1=DONE、**bit2=ERR——同一位按上下文解释：正常帧路径=帧错误（ghost start/非法层/AXI 错误，ERR=1 时 OUT 无效勿读）；软复位路径=RESET_FAIL（见三）**。FPGA 受理新 START 时重写 STATUS=busy 覆盖一切残值（含 DONE/ERR，无需显式 CLR；ARM 只读，不写 STATUS）。ARM 轮询 1ms、超时 15s |
| +0x14 | LAYER | ARM 写 | bit[7:0]=停止层 N；bit8=跳 ReLU（对拍导出即得 pre-ReLU）；bit9=跳池化；[31:10] 保留（写啥读回啥，FPGA 内部截弃）。**越界钳制（RTL 实码口径，mfl_ctrl_fsm）**：N≤9 原样；0x0A~0x0F 按 9；**N≥0x10 取低 4 位后按前两条**（如 0x10 只跑 L0、0x1F→0xF→9）；**低 8 位==0xFF 时停止层特判为 9（全链），bit8/bit9 仍按原语义生效**（故 0x2FF=跳池化全链、0x1FF=跳 ReLU 全链）。常用值：0xFF 全链 / 0x2FF 跳池化全链 / **0x300\|N 逐层对拍导出**（pre-ReLU pre-pool，OUT_ADDR 指空闲 scratch——**按大小分档路由**：N=0/1/2/7/8/9→scratch B `0xD00000`、N=3/4/5/6→scratch A `0x500000`，导出完恢复 `0x470000`。注意与引擎层间"偶层写 A/奇层写 B"的 FSM 自管规则是两回事，勿混） |

### 两字（0x18/0x1C）

| 偏移 | 寄存器 | 方向 | 语义 |
|---|---|---|---|
| +0x18 | VERSION | FPGA 写一次 / ARM 只读 | 位流 build ID，**兼作 RESET 可用性核验**（判定协议见三.1：配置主判 + 本值格式核验）。编码：**[29:0]=位流定案日期 0xYYYYMMDD；[31:30]=同日修订号**（00=当日首版；01~11=当日第 2~4 版，高位非零即多版标志、不伪装成次日日期）；RTL 行为变更时刷新。**硬约束：每个交付位流必须"VERSION 非 0 ⟺ RESET 已实现"，不允许只开其一**（半实现位流会让 ARM 写 RESET 空等 1s 后误判失败去 reboot）。软复位不重写本字；整板 reboot 重新配置同一份位流时值不变（**换位流才换代际——这正是 VERSION 的用途**）。当前位流值 0x20261018 |
| +0x1C | RESET | ARM 写 1 / FPGA 处理完自清 0 | 软复位触发（协议与时序见三），1s 上限 |

**握手时序（正常推理路径）**：ARM 写 IN/OUT/LAYER → CTRL|=start →（FPGA 清 CTRL、写 STATUS=busy、推理）→ FPGA 写 STATUS=done → ARM 读输出。**ARM 不写 STATUS（只读；FPGA 受理下一帧 START 时重写覆盖残值）**。

## 三、软复位协议

**背景**：板无 fpga_manager，位流随 BOOT 上电加载；ARM 无 PU 复位控制。15s 推理超时后若无软复位手段只能整板 reboot，现场代价大。

1. **可用性判定（配置主判据 + VERSION 核验）**：**主判据 = 部署配置**——软复位可用性与位流代际对齐（部署侧已知信息），驱动 cfg 按位流版本配置；配置不可用（旧位流/默认关闭）→ 超时**直接降级整板 reboot，不读不写新字**。配置可用时**核验**：读 VERSION 应匹配其编码格式（[31:30]=同日修订号、[29:0]=0xYYYYMMDD 日期、年份 ≥0x2026）；不匹配 = 位流/配置错配或 DDR 残值 → 报警并走降级路径，**不得写 RESET**。**原因**：DDR 邮箱架构下，未实现字读回的是 **DDR 残值**（非可靠 0），且 ARM 写入会驻留 DDR、FPGA 未实现时无人自清（写 RESET 后轮询必超时）——"VERSION 非 0 即可用"不成立。配合 §二 VERSION 行的 ⟺ 硬约束。
2. **复位流程与写序**：ARM 写 RESET=1 → FPGA 排空并复位本地适配器/AXI 主/M8/M2/mux（**复位本地 AXI 主并丢弃本地在途状态；下游 SPS0/DDR 已接收的事务无法撤回**——复位前已发出的在途写可能已落在 OUT/scratch，复位后不得当有效结果读取）→ FPGA **先写 STATUS、最后清 RESET=0**（保证 ARM 看到 RESET=0 时 STATUS 必已就绪，不会读到复位前旧值）：干净复位 STATUS=**0x0**；排空失败 STATUS 置 **bit2**（复合值 0x6=done\|RESET_FAIL，bit1 表复位流程完成、bit2 表结果失败）→ ARM 读回判定。全程 **1s 上限**。
3. **复位后重启**：复位完成（RESET 归零）后，ARM **必须重走完整启动写序**（IN_ADDR/OUT_ADDR/LAYER/CTRL——内部受理状态已回初始，邮箱参数字虽未清除也不可跳过写序）再提交新帧。
4. **复位范围硬边界**：**不动 DDR 任何内容**（IN/OUT 帧、scratch、demo 数据）；邮箱内只清 CTRL/STATUS/RESET 三字；**不清 IN_ADDR/OUT_ADDR/SLOT/LAYER/VERSION**（运行参数保留，供复位后现场诊断超时原因）。
5. **复位期间 FPGA 忽略新 CTRL.start**（复位优先；完成后 CTRL=0x0 干净起点，防复位刚清完即被触发的竞态）。
6. **失败处置链（ARM 侧）**：复位后读到的 **0x6 = RESET_FAIL**（≠正常帧的 0x6=帧错误，**驱动不得把复位后的 0x6 当帧错误直接重试发帧**）→ 允许重试一次软复位 → 仍失败整板 reboot；失败与重试期间不下发新帧。
7. **兼容策略**：FPGA 生产实现默认关闭两字（VERSION 恒 0 / RESET 写无效），ARM 驱动按"不存在"处理（超时直接降级 reboot）；启用后 VERSION=0x20261018，与位流代际对齐。

## 四、FPGA 侧实现的硬性要求

1. **邮箱写必须 honor WSTRB**：写侧按字节 lane 掩码 `0xF << addr[3:0]` 发 WSTRB——邮箱 128bit beat 内 4 个字，不 honor 会打坏邻字寄存器。+0x18/+0x1C 与 +0x10/+0x14 同处一个 128bit beat，掩码处理路径与现有字一致。
2. **AXI 契约**：单 aclk 域；C_DW=128；ID[3:0]；len[7:0]；邮箱用单拍读（arlen=0）；frame_reader 突发读 ≤256 拍；stream_writer 段写+尾拍 wstrb 掩码；每 master 单 outstanding；读延迟容忍 4~19 拍随机 + 25% 单拍间隙。
3. **数据格式**：输入 `int8[1][3][480][1024]`（1,474,560B）；实模式输出 `int8[1][96][15][32]`（46,080B，conv09+ReLU+pool 全在 FPGA 侧完成）。
4. **层间 scratch 奇偶规则**（引擎 FSM 自管，不用配）：偶层写 A、奇层写 B，本层输入=上一层输出。
5. **权重五件套在片上 ROM**（$readmemh 装载：weights/bias/mc/layer_config/boundary；boundary.mem 为边界 requant 标量、**片上**在池化后下层 conv 前施乘移位），与共享窗无关，勿占 DDR。
6. **VERSION 为常量寄存器**：综合期固定或上电写一次后运行时只读；软复位不重写，整板 reboot 重新配置同一份位流时值不变（换位流才换代际）。
7. **邮箱页未用偏移 0x20~0x3F 双方均勿使用**：当前 `0x301000` 为 **DDR 邮箱**——ARM 经共享窗直读写 DDR，FPGA 作 AXI 主机经 regbox 引擎轮询/回写，**无 FPGA 从机译码环节**。实际约束双向：(a) **FPGA 主机侧访问序列**（regbox 引擎读写清单）不含未用偏移——现行实现已满足；(b) **ARM 勿把未用偏移当自由内存**——为将来页内扩字保留。将来扩字 = 地址表新增字 + regbox 引擎访问序列加字，走变更流程，**不涉及控制面架构变更**。

## 五、禁改清单与两套协议提示

- 邮箱页 64B（0x301000~0x30103F）内现已用 **0x00~0x1C 八字**；0x20~0x3F 为页内预留空位；`0x301040~0x302000` 勿用。**不得自行挪动或自选新址**；任何变更提出具新版并经双方确认后生效；单一事实源 = 本表 + ARM 侧驱动寄存器头文件。
- 板上另有一套 **frame demo 协议**（MAGIC "KOSM"/帧描述符）——与 MFL 邮箱协议是**两回事，且不共存于同一位流**。demo 帧数据区在窗内 `0x2000` = **物理 0x302000，与 IN slot0 是同一块**——两套位流互斥、切换时不得混用该区域。
- 寄存器语义疑问提地址表出具方对接，勿按本表独立发挥。
